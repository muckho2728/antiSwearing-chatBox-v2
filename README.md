# 🚫 Anti-Swearing Chat Box V2

**Anti-Swearing Chat Box V2** is a real-time messaging application designed to promote respectful communication by **automatically filtering offensive or inappropriate language**. This version offers improved performance, better UX, and easier extensibility compared to its predecessor.

---

## ✨ Features

- ✅ **Profanity Filtering:** Automatically detects and censors inappropriate language in real-time.
- 💬 **Instant Messaging:** Smooth and seamless real-time chat between users.
- ⚙️ **Customizable Word List:** Admins can define and manage the list of forbidden words.
- 🖥️ **User-Friendly Interface:** Clean and intuitive UI for all users.
- 🔌 **Extensible:** Easily integrable with other platforms or future enhancements.

---

## 🛠 Prerequisites

Make sure the following are installed:

- [Git](https://git-scm.com/)
- A modern web browser (Chrome, Firefox, etc.)
- [Node.js](https://nodejs.org/) or [Python](https://www.python.org/) depending on your setup

---

## 🚀 Installation

1. **Clone the repository:**

```bash
git clone https://github.com/muckho2728/antiSwearing-chatBox-v2.git
cd antiSwearing-chatBox-v2
```

2. **Install dependencies:**

```bash
# For Node.js users
npm install

# For Python users (if applicable)
# pip install -r requirements.txt
```

3. **Configure environment variables:**

- Create a `.env` file if required.
- Add configuration values such as `PORT`, `FORBIDDEN_WORDS`, etc.
- Refer to `.env.example` if available.

4. **Run the application:**

```bash
# For Node.js
npm start
```

Then open your browser and go to:  
`http://localhost:3000` (or your configured port)

---

## 🧑‍💻 Usage

1. Open the app in your browser.
2. Log in or start chatting right away.
3. Send messages — the system will automatically filter out any offensive content.
4. If implemented, admins can update the forbidden word list via the admin panel.
