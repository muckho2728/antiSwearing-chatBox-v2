# Anti-Swearing Chat Box V2 Anti-Swearing Chat Box V2 is a real-time chat application designed to create a friendly and respectful communication environment by automatically filtering out inappropriate or offensive language. This project aims to provide a safe space for users to interact without worrying about profanity or harmful content. ## Features - **Profanity Filtering:** Automatically detects and censors inappropriate words in chat messages. - **Real-Time Chat:** Supports instant messaging between users. - **Customizable Word List:** Allows administrators to define a list of forbidden words. - **User-Friendly Interface:** Simple and intuitive design for seamless user experience. - **Extensible:** Easily integrate with additional features or platforms. ## Prerequisites Before you begin, ensure you have the following installed: - [Node.js](https://nodejs.org/) (version 14.x or higher) - [Git](https://git-scm.com/) for cloning the repository - A modern web browser (e.g., Chrome, Firefox) ## Installation 1. **Clone the Repository:** ```bash git clone https://github.com/muckho2728/antiSwearing-chatBox-v2.git cd antiSwearing-chatBox-v2 ``` 2. **Install Dependencies:** ```bash npm install ``` 3. **Configure Environment:** - Create a `.env` file in the root directory. - Add necessary configurations (e.g., database connection, API keys): ```plaintext PORT=3000 FORBIDDEN_WORDS=word1,word2,word3 ``` 4. **Run the Application:** ```bash npm start ``` The application will be available at `http://localhost:3000`. ## Usage 1. Open the application in your browser. 2. Register or log in to start chatting. 3. Type your messages, and the system will automatically filter out any inappropriate words. 4. Administrators can update the list of forbidden words via the admin panel (if implemented). ## Contributing We welcome contributions to improve Anti-Swearing Chat Box! To contribute: 1.
